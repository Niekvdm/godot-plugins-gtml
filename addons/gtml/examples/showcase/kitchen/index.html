06 · CSS authoring

All three samples in this showcase use the features below:

  • --name custom properties + var(--name)
  • calc() for derived dimensions
  • transform: scale / translate / rotate animated via transitions
  • Structural selectors: :first-child, :nth-child(2n+1), :not(...)
  • Substring attribute matchers: [href^="https"], [class~="card"]
  • Sibling combinators: .a + .b, .a ~ .b
